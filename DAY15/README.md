3. STL :- SET :- 

A set store  unique elements only and keep them sorted.

when to use :- 
1. when you need unique sorted elements
2. Searching becomes o(log n)

=====================================================================================

container ||           Property        || best usecase
Vector    ||   dynamic array           || random access + fast insert at end.
list      ||   doubly linked list      || freuqent insert/delete 
set       || unique sorted             || remove duplicate , fast search 
Map       || key - value               || key sorted
