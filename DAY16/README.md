File Handling in C++


Cpp provides file handling using the <fstream> header :- 

Main Classes 
class        purpose 
ofstream      write data to file 
ifstream      Read data from file 
fstream    write + Read 

:- 

open() -> open file 
close() -> close file 
ios::out  -> write mode 
ios::in -> Read Mode 
ios::app -> append data 

fstream is used for the file handing .
