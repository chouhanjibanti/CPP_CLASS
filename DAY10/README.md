Multiple Inheritance :- 

one child class having multiple parent classes.

      ClassA     ClassB
         \     /
          \   /
         ClassC


         MULTIPLE INHERITANCE — 3 Coding Questions

Q1. Create two parent classes: Teacher & Researcher
Teacher → function teach()
Researcher → function research()
Child class Professor inherits both → professorInfo()
Create object of Professor & call all three functions.


Q2. Class Engine & class Body → class Car
Engine: function enginePower()
Body: function bodyType()
Car: function carInfo()
Create object of Car & display all details.


Q3. Class Father & class Mother → class Child
Father: function sayFatherName()
Mother: function sayMotherName()
Child: function sayChildName()
Create object of Child & call all functions.

Heirachical Inheritance :- 

one super class having multiple sub classes is known as Heirachical Inheritance.


HIERARCHICAL INHERITANCE — 3 Coding Questions
Q1. Class Shape → Circle & Rectangle
Shape: input values
Circle: calculate area of circle
Rectangle: calculate area of rectangle
Use separate objects for Circle and Rectangle.


Q2. Class Animal → Dog & Cat
Animal: function eat()
Dog: function bark()
Cat: function meow()
Call functions using respective objects.


Q3. Class Vehicle → Bike & Car
Vehicle: common function start()
Bike: function twoWheeler()
Car: function fourWheeler()
