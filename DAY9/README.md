Inheritance :- 

Definition :- one class (child) acquires properties of another class(parent class).
                 OR
we can inherit the property/member from one class to another class.

Mainly we have Diff Types of Inheritance :- 
1. Single level Inheritance
2. Multiple Level Inheritance
3. Multiple Inheritance
4. Herachical Inheritance
5. Hybrid Inheritance


Definitions:- 
1. Single level Inheritance :- inheritance with respect single level.
2. Multi Level Inheritance :- Inheritance with respect multi level.
3. Multiple Inheritance :- Only one child class , multi parent class in the same level.
4. Herachical Inheritance :- only one parent class , multi child class in the same level. 
5. Hybrid Inheritance :- combination of any two inheritance is known as hybrid inheritance.
